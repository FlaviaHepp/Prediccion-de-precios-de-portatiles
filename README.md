# Prediccion-de-precios-de-portatiles
Predicción de Precios de Computadoras Portátiles

Implementación de un sistema basado en aprendizaje automático para predecir precios de computadoras portátiles, utilizando especificaciones técnicas como variables predictoras.
Exploración de Datos: Análisis exhaustivo del dataset, detección y manejo de valores faltantes, conversión de tipos de datos, y análisis de correlación para identificar relaciones clave entre las variables.
Ingeniería de Características: Creación de nuevas variables predictoras como el número total de píxeles en base a la resolución de pantalla.
Visualización: Generación de gráficos descriptivos utilizando Matplotlib y Seaborn para identificar tendencias y patrones en las características del producto.
Modelado Predictivo:
Aplicación de múltiples algoritmos de regresión (Linear Regression, Ridge, Lasso, ElasticNet) para ajustar el modelo predictivo.
Comparación de métricas de rendimiento (MSE, r²) para seleccionar el modelo más adecuado.
Preprocesamiento Avanzado: Escalado de datos con MinMaxScaler, codificación de variables categóricas mediante Label Encoding y división eficiente de datos en conjuntos de entrenamiento y prueba.
Tecnologías Utilizadas: Python (pandas, numpy, seaborn, matplotlib, scikit-learn), técnicas de regresión, análisis exploratorio y visualización de datos.
Resultados: Construcción de un modelo predictivo con precisión evaluada mediante métricas de error cuadrático medio (MSE) y coeficiente de determinación (r²), proporcionando predicciones confiables para los precios de portátiles.
